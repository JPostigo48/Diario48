# Sprint 03 — Music Tracker

## Objetivo del sprint

Definir y preparar el desarrollo web inicial de `music tracker` como una herramienta real de biblioteca musical personal, priorizando:

- lógica de dominio correcta;
- arquitectura limpia;
- separación de responsabilidades;
- persistencia robusta;
- base extensible para importación, revisión manual, deduplicación y exportación.

Este sprint toma como fuente principal:

- `docs/IA/logica-de-funcionamiento/proyectos/music tracker/01-prompt_biblioteca_musical_personal.md`
